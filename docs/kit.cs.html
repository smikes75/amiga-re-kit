Kit je stavěný tak, aby ho řídil AI agent. Jednostránkové zadání agentovi řekne pravidla (měřit, nehádat; herní data zůstávají mimo git), jak kit nastavit a v jakém pořadí jít. Claude Code ho načte jako CLAUDE.md; jiný agent ho dostane jako první zprávu.

Stáhnout zadání (arek-agent.cs.md) English version

Čtyři kroky, nic dalšího se nenastavuje. Agent si od vás vyžádá cestu k obrazu diskety; obraz zůstává na vašem počítači.

pip install "amiga-re-kit[mcp]"
mkdir hra && cd hra && arek init .
# do local.conf zapsat cestu k .adf (ADF1=…)
# arek-agent.cs.md uložit sem jako CLAUDE.md
claude      # „Přečti CLAUDE.md a změř disketu.“

Změř originál, než na něj sáhneš.

Nástroje pro reverzní inženýrství disketových her z Amigy, vytažené ze čtyř přestaveb her. Mapy entropie, packery, přísný dekodér a rekompilátor 68000, snímky z bezhlavého emulátoru – a MCP server, aby stejné přístroje držel v ruce i asistent.

pip install amiga-re-kit a arek adf map disk.adf udělá totéž z terminálu.

Nahrajte obraz diskety a uvidíte: velikost a SHA-256, typ a kontrolní součet boot bloku, oblasti po stopách, signatury packerů (PP20, RNC, ATN!, IMP!, …) a bloky Bytekilleru ověřené vlastním kontrolním součtem – výstup `arek adf info` a `arek scan`.

Metoda

Každý krok dává měření, proti kterému se kontroluje krok další. Nic dál po proudu nestojí na odhadu, a proto takto vzniklým dokumentům může věřit i ten, kdo hru nikdy neviděl.

  1. Inventura obrazu

    Velikost, SHA-256, boot blok. Každé pozdější tvrzení se vztahuje přesně k tomuto obrazu; crackované dumpy se liší.

  2. Podívat se, než začneš číst: mapa entropie

    Kde je kód, kde zabalený blob, kolik souborů tam nejspíš je – dřív, než se dekóduje jediná instrukce.

  3. Zaváděcí řetězec a packery

    Projít boot blok, sledovat trackloader k další fázi, najít packery podle signatury nebo přečtením rozbalovací rutiny. Každý rozbalovač ověřit bajt po bajtu proti RAM emulátoru.

  4. Najít katalog přes kód

    Číst tabulku souborů tak, jak ji čte loader. Datové formáty mají mnoho věrohodných čtení; kód má jedno.

  5. Hranice hardwaru

    Které rutiny jsou čistý výpočet a které opravdu řídí Agnus, Denise a Paulu. Většina hry bývá to první.

  6. Rekompilovat a ověřit

    68k do C, rutinu po rutině, spustit nad otiskem RAM originálu a porovnat s otiskem pořízeným poté. Shoda, nebo není hotovo.

  7. Ověřit proti skutečnosti, ne proti očím

    Deterministické snímky z bezhlavého emulátoru ve známých časech, se skriptovaným vstupem, jako regresní kontrolní body.

Dlouhá verze s příkazy: docs/METHOD.md (anglicky). Nastavení bezhlavé vAmigy: docs/HEADLESS.md (anglicky).

Z asistenta

MCP server nabízí stejné přístroje Claude Code nebo kterémukoli MCP klientovi. Každý nástroj bere cesty na vašem počítači a vrací měření – mapu entropie, výpis, diff – nikdy obraz samotný. Relace se čte jako laboratorní deník: zmapuj disketu, najdi zabalené bloky, rozbal ten na 0x1f40 a projdi ho od vstupu, řekni, které rutiny sahají na hardware, jednu rekompiluj a porovnej její zápisy s otiskem originálu.

Nainstalujte pip install "amiga-re-kit[mcp]" a zaregistrujte server:

// .mcp.json ve vašem projektu
{
  "mcpServers": {
    "arek": { "command": "arek-mcp" }
  }
}

// 26 nástrojů v pořadí, v jakém je použijete

adf_ls         adf_file       adf_extract    scan_packed
